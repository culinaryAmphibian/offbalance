WebApp -[hidden]right- ProtoMgr
DB -[hidden]down- Escrow

' ---------------- Actors ----------------
Buyer --> WebApp : submit job /\nview result
Provider --> WebApp : register /\ndashboard
Provider --> VM : install VM,\nallocate resources

' ---------------- Web -> Server ----------------
WebApp --> API : HTTPS + JWT\n(Sign-In With Ethereum)

' ---------------- Server internals ----------------
API --> DB : accounts, jobs,\nhardware, images
API --> Matcher : new job
Matcher --> ProtoServer : top-k providers
API --> ServerBCM : post job

' ---------------- Server <-> Chain ----------------
ServerBCM --> Escrow : submitJob() + escrow;\nlisten for status events

' ---------------- Server <-> Provider ----------------
ProtoServer --> ProtoMgr : TLS "backdoor" port:\nassignment, Docker image,\n<- full result
Bench --> API : POST machineSpecs

' ---------------- Provider internals ----------------
ProtoMgr --> Docker : run container
ProtoMgr --> ProvBCM : request signed tx

' ---------------- Provider -> Chain ----------------
ProvBCM --> Registry : register, stake,\nsession key
ProvBCM --> Escrow : acceptJob,\ncommit / reveal hash

' ---------------- Chain internals ----------------
Escrow --> Registry : eligibility,\nlock / slash stake

legend bottom
  | **Off-chain (Server)** | **On-chain (Contracts)** |
  | Provider pool cache (live sessions) | Escrow buyer funds |
  | Filter by min specs + price | Track job status |
  | Pick top-k providers | Commit / reveal of result HASHES only |
  | Deliver Docker image over TLS | Consensus against quorum |
  | Collect full results, send consensus result to buyer | Pay winners, slash losers |
endlegend
